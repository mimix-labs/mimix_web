# Glosario de Ciencia

- **Celda de elemento:** botón de la tabla periódica con número, símbolo y nombre.
- **Pinch:** gesto de unir índice y pulgar para seleccionar una celda o un control.
- **Vista atómica:** pantalla enfocada que muestra el modelo de Bohr del elemento elegido.
- **Categoría química:** clase visual de un elemento, como halógeno o gas noble.
